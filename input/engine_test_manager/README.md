# Engine Test Manager

Offline desktop application for recording and tracking engine test results.

## Project
- Flutter desktop application
- Local SQLite database
- Persian user interface
- Windows desktop target

## Build
Run `flutter pub get`, then `flutter build windows --release`.

This is an initial prototype. User management, access control, audit history, Excel/PDF reports, backup and restore, system tray, installer packaging, barcode workflow, and Windows 7 compatibility are planned for later stages.
